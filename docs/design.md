# Design Guidelines

The site should read like a quiet academic personal page: direct, structured, and easy to scan from top to bottom.

## Principles

- Prioritize readability over presentation. The main experience is text, not visual effects.
- Organize information in logical sections with clear headings and compact supporting details.
- Prefer a single-column flow for primary pages. Use lists for experience and projects.
- Keep project images as supporting evidence, not dominant marketing visuals.
- Use restrained interaction states: link underlines, focus outlines, and subtle background changes only.

## Visual Style

- Use a neutral paper palette: off-white page background, white surfaces, charcoal text, gray metadata, and an understated academic blue for links.
- Use serif typography for body content and headings.
- Use system sans-serif for navigation, dates, tags, labels, and other UI metadata.
- Avoid large hero type, heavy shadows, glass effects, loud gradients, decorative cards, and image zoom/lift animations.
- Keep borders thin and functional. Cards should only appear when a piece of content genuinely needs framing.

## Page Patterns

- Home page: profile summary, compact facts, experience, selected work, footer.
- Projects page: one vertical list of projects ordered by date.
- Project pages: contained hero image, title/date/source/tags, readable prose, optional interactive demos, and quiet section navigation on wide screens.
- Mobile layouts should remain linear, with images and metadata shrinking before text readability is compromised.
